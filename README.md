# Hi, I'm Cyril 👋

I'm a software engineering student at **EPITA**.

I enjoy programming, understanding how software works and learning new things through projects. I like exploring different areas of computer science, from low-level programming to networking and application development.

Most of the repositories on this profile are personal projects. I built them at different times and published them on GitHub later, after cleaning and organizing them.

I also keep the conventions I learned during my studies: consistent formatting, simple project structures, readable README files, clear Makefiles, tests and CI when they are useful.

## Projects

### Main projects

- **[my-42sh](https://github.com/cyril-huet/my-42sh)** — A small Unix shell written in C99, with pipes, redirections, builtins and variable expansion.
- **[EPICheck](https://github.com/cyril-huet/epicheck)** — A C11 command-line tool for checking formatting, compilation and basic code quality rules in C and C++ projects.
- **[MiniGit](https://github.com/cyril-huet/minigit)** — A small Git-inspired version control system written in C++17, with staging, commits, branches and file differences.
- **[HTTPd](https://github.com/cyril-huet/HTTPd)** — An educational HTTP/1.1 server written in C, with static file serving, configuration and logging.
- **[MyMalloc](https://github.com/cyril-huet/MyMalloc)** — An educational memory allocator written in C, implementing malloc, free, calloc and realloc.
- **[OCaml Crypto Lab](https://github.com/cyril-huet/ocaml-crypto-lab)** — An OCaml project exploring number theory, classical ciphers and basic cryptographic algorithms.

### Other projects

- **[MyASAN](https://github.com/cyril-huet/MyASAN)** — An educational C11 library for tracking allocations and reporting memory leaks and some memory errors.
- **[MiniRedis](https://github.com/cyril-huet/MiniRedis)** — A small Redis-like TCP server and command-line client written in C99.
- **[MiniMakefile](https://github.com/cyril-huet/Minimakefile)** — A small make-like build tool written in C99.
- **[Evalexpr](https://github.com/cyril-huet/Evalexpr)** — An arithmetic expression evaluator written in C99, supporting infix and reverse Polish notation.
- **[Tinyprintf](https://github.com/cyril-huet/Tinyprintf)** — A small printf implementation written in C99.
- **[The Rock Scape](https://github.com/cyril-huet/The_Rock_Scape)** — The website, documents and downloadable game for an EPITA team project. I worked on the website and interface.
