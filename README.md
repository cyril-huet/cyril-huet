# Hi, I'm Cyril 👋

I'm a software engineering student at **EPITA**.

I enjoy programming, understanding how software works and learning new things through projects. I like exploring different areas of computer science, from low-level programming to networking and application development.

Most of the repositories on this profile are personal projects. I built them at different times and published them on GitHub later, after cleaning and organizing them.

I also keep the conventions I learned during my studies: consistent formatting, simple project structures, readable README files, clear Makefiles, tests and CI when they are useful.

## Projects

### Main projects

- **[EPICheck](https://github.com/cyril-huet/epicheck)** — A C11 command-line tool for checking formatting, compilation and basic code quality rules in C and C++ projects.
- **[MiniGit](https://github.com/cyril-huet/minigit)** — A small Git-inspired version control system written in C++17, with commits, branches, staging and file differences.
- **[my-42sh](https://github.com/cyril-huet/my-42sh)** — A Unix shell written in C99, supporting pipes, redirections, variables, builtins and subshells.
- **[HTTPd](https://github.com/cyril-huet/HTTPd)** — An HTTP/1.1 server written in C, with request parsing, static file serving, configuration and logging.
- **[MyASAN](https://github.com/cyril-huet/MyASAN)** — An educational memory debugging tool written in C11 to track allocations, memory leaks and common memory errors.
- **[The Rock Scape](https://github.com/cyril-huet/The_Rock_Scape)** — A cooperative 2D escape game developed as a team project at EPITA, with a website presenting the game and its development.

### Other projects

- **[MyMalloc](https://github.com/cyril-huet/MyMalloc)** — A small memory allocator written in C, implementing `malloc`, `free`, `calloc` and `realloc`.
- **[MiniRedis](https://github.com/cyril-huet/MiniRedis)** — A simple Redis-like TCP server written in C99, with basic key-value operations.
- **[MiniMakefile](https://github.com/cyril-huet/Minimakefile)** — A small build tool written in C99, inspired by GNU Make.
- **[Evalexpr](https://github.com/cyril-huet/Evalexpr)** — An arithmetic expression evaluator written in C99, supporting infix and reverse Polish notation.
- **[Tinyprintf](https://github.com/cyril-huet/Tinyprintf)** — A small implementation of `printf` in C99, using variadic arguments and manual conversions.
- **[OCaml Crypto Lab](https://github.com/cyril-huet/ocaml-crypto-lab)** — An OCaml project exploring number theory, classical ciphers and basic cryptographic algorithms.
